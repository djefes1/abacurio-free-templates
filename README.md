# Abacurio free spreadsheet templates

Free Excel and Google Sheets templates from **[Abacurio](https://abacurio.com/)**, a free online calculator website in 16 languages: budget planners, 2027 calendars with public holidays, shift schedules, invoices, loan and debt planners, savings challenges and more.

- **Free** for personal use and for use inside your own business. No sign-up and no macros: plain formulas you can read and change.
- Each template has its own page on abacurio.com with a preview, instructions and a printable PDF.
- Made by Furkan Çetinkaya ([About Abacurio](https://abacurio.com/about/)).

Download a file from the folder for your language, or open the template's page for the description and preview.
